# SaaS Financial Performance Analytics

## Overview
A financial analytics project for a fictional SaaS company, Nexora Technologies, covering January 2025 – December 2026.

## Tools
- Excel
- Databricks SQL
- Power Query
- Power BI
- DAX

## Data
6 datasets and 9,440 records covering customers, subscriptions, invoices, expenses, budgets, and subscription events.

## Dashboards
1. **Executive Financial Overview** – Revenue and collections.
2. **Revenue & Subscription Analysis** – MRR, ARR, and subscriptions.
3. **Expenses & Profitability** – Expenses and budget performance.

## Key Results
- Total Invoiced: $17.43M MXN
- Total Collected: $13.68M MXN
- MRR: $1.56M MXN
- ARR: $18.72M MXN
- Total Expenses: $57.98M MXN
- Budget Utilization: 99.24%

## Objective
Practice data analysis, SQL querying, data modeling, DAX calculations, and interactive dashboard development.
